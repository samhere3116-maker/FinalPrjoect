# MindMate

A mood-adaptive desktop recommendation system built in Java Swing.

## What it does

MindMate detects the user's current mood and recommends personalized content/game suggestions based on it. It supports multiple user profiles, so different users get tailored recommendations on the same app.

## Features

- Mood detection across multiple emotional states
- Personalized content/game recommendations based on detected mood
- Multi-user profile support

## Tech Stack

- Java
- Java Swing (GUI)
- Built and run in NetBeans

## How to Run

**Option 1 — From source (NetBeans)**
1. Clone this repository: git clone https:https://github.com/samhere3116-maker/FinalPrjoect

2. Open NetBeans → File → Open Project → select the cloned folder
3. Right-click the project → Run

**Option 2 — Runnable JAR (no NetBeans needed)**
Download the `.jar` file from the Releases section and double-click to run (requires Java installed).

## About
